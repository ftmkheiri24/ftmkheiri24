## 🎓 Research Background

### Climate Change Impact on Urban Flooding

My master's research investigated how future climate conditions could influence urban flooding using hydrological, hydraulic, and spatial modeling techniques.

The research involved:

* Climate-change scenario analysis using CMIP6 climate models
* Statistical downscaling of precipitation data
* Design-storm development for different return periods
* Rainfall–runoff modeling
* 1D and 2D urban flood simulation
* Urbanization scenario analysis
* Sensitivity analysis of hydrological parameters
* GIS-based spatial analysis
* Sentinel-1 satellite flood mapping

## 🚀 Featured Project

### 💧 Daily Streamflow Prediction with Machine Learning

A reproducible Python and machine-learning project for predicting daily streamflow using antecedent hydrological conditions and time-series features.

The project includes:

* Hydrological data preparation and quality control
* Exploratory data analysis
* Lagged streamflow features
* Rolling hydrological statistics
* Time-based training and testing
* Machine-learning model development
* Hydrological performance evaluation
* Reproducible notebooks, figures, and outputs
