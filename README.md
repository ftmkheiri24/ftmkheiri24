## 🎓 Selected Research Projects

### Climate Change Impacts on Urban Flooding — M.Sc. Thesis

* Analysed a 1967–2019 rainfall record for the Hachiroud catchment and downscaled projections from five CMIP6 GCMs under three SSPs using LARS-WG8.
* Derived 24-hour design storms for eight return periods (2–200 years) using GEV analysis and the SCS Type IA temporal distribution.
* Simulated historical and future rainfall-runoff response in PCSWMM/SWMM5.2 and compared results across four future periods, climate models, and scenarios.

### Directional Urban Expansion and Flood Response

* Developed 72 scenarios in a semi-distributed 1D PCSWMM model, combining three urban-development intensities, three expansion directions, and eight design-storm return periods.
* Analysed changes in runoff, infiltration, outfall discharge, and node-surcharge duration; upstream-focused expansion produced greater runoff increases than downstream expansion at the same impervious cover.

### Selected Hydrology and Geospatial Work

* Modelled rainfall-runoff in HEC-HMS for the Khorramabad watershed, compared stream-network extraction methods in the Kuchesfahan watershed, and used HAND to map flood-prone areas along the Ghezel Ozan River.
* Compared Copernicus climate datasets for the Maragheh and Ravansar stations and evaluated ArcGIS interpolation methods.

## 🚀 Featured Machine-Learning Project

### 💧 Next-Day Streamflow Prediction

A reproducible Python workflow for predicting next-day streamflow in the Potomac River using lagged discharge features and a Random Forest regressor.

The project includes:

* Daily streamflow preparation for 2015–2024
* Lagged discharge features
* Chronological training and testing to avoid temporal leakage
* A persistence baseline for comparison
* Random Forest regression
* Evaluation using MAE, RMSE, and R²
* A documented Jupyter Notebook workflow
