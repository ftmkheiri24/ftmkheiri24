## 🚀 Featured Project

### 💧 Daily Streamflow Prediction with Machine Learning

A beginner-friendly and reproducible machine learning project for predicting next-day streamflow using daily discharge observations and antecedent hydrological conditions.

The project includes:

* Hydrological time-series preparation
* Exploratory data analysis
* Lagged and rolling hydrological features
* Time-based train and test splitting
* Machine-learning model development
* Hydrological performance evaluation
* Reproducible notebooks and outputs
